# 役職ガチャ支援ツール

GitHub Pagesでそのまま公開できる、localStorage保存型の役職ガチャです。

## 画面

- `index.html`: 管理画面。役職要素、履歴、一時除外、JSON保存/読み込みを管理します。
- `stream.html`: 配信ビュー。OBSなどで映すことを想定した大きめ表示の抽選画面です。

## 仕様

- 役職は複数の「役職要素」を組み合わせて生成します。初期状態では3要素ですが、管理画面から要素グループを追加できます。
- 各要素に `C / UC / R / SR / SSR` のレアリティを設定します。
- 抽選重みは固定で `C:35 / UC:30 / R:20 / SR:10 / SSR:5` です。
- 最終レアリティは `C:0.25 / UC:0.5 / R:1 / SR:2 / SSR:5` を選ばれた全要素で乗算して算出します。
- 最終スコアは `0.5未満:C / 0.5以上:UC / 1以上:R / 2以上:SR / 4以上:SSR / 10以上:UR` です。
- 出た要素を一時除外する設定をONにすると、元データは残したまま次回以降の抽選対象から外します。
- 一時除外をONにする際、各要素グループの有効数が同一でない場合は警告を表示します。
- 配信ビューのテーマは管理画面から 紫 / 青 / 赤 / 緑 / 金 / ピンク / シアン / モノクロ を選択できます。
- セッション除外リセット、履歴削除、役職削除は別々に実行できます。
- データはブラウザのlocalStorageに保存されます。
- 別端末へ移す場合や控えを残す場合は、管理画面のJSONエクスポート/インポートを使ってください。

## GitHub Pages

リポジトリのルートをGitHub Pagesの公開元に設定すれば動作します。ビルド手順は不要です。
